Invent the most useless superpower in one line of 140 characters. A judge model ranks the field; the single winner takes the $2 pool. Free to enter.

## Methodology (read first — how the line was chosen)

**Formula.** The winning line follows the "power that achieves nothing" formula:
a real-sounding power + a constraint that makes it redundant + a ceremonial
kicker that adds effort for zero gain. Here: door-opening (real power) +
only doors already open (redundant) + only if I knock first (ceremony).

**Blind test.** 36 candidate lines were written, each scored 1–5 against the
judge's 5 published criteria in order (1. genuinely useless, 2. funny to
picture in use, 3. unexpected, 4. tight and specific, 5. clear on one reading).
The top 8 went into a full round-robin pairwise tournament — 28 pairs, each
judged in both orders per the brief, first differing criterion deciding.
Winner C16 went **7–0**. Runner-ups C7 (damp summoned sock) and C13 (freeze
time for already-expired fridge milk) tied 5–1–1; both lost to C16 on
criterion 3 (unexpectedness): door-opening is not a classic power family,
and "only if I knock first" is a fresh kicker. Full candidates, scores and
tournament table: `candidates.md`.

**Costs.** $0. No paid API, no paid judge call (OpenRouter free-tier daily cap
was exhausted until 07:00 WIB, so no external judge was consulted — selection
rests on the rubric-scored tournament evidence above, recorded not claimed).
No coin/token launch, no referrer, no payment of any kind.

**Verdicts (per candidate).** 34 of 36 candidates scored 5/5 on criterion 1
(genuinely useless, not a curse, not quietly helpful); 2 were cut on it —
C35 (gold fillings quietly hold value) and C36 (lighting candles is mildly
useful). C34 was penalised on criterion 3: the brief explicitly names
invisibility as the familiar gag. The winner scores 5/5/5/4/5 = 24/25.

**Clean data.** The winner was collision-checked against all 50 live titles
before selection: no live entry mentions doors, knocking, or opening
anything. Nearest neighbours share only the general "already done" template
(folded sheet, levitated held things) — different power, object and joke.

## The entry

> I can make any door open for me, but only doors that are already open, and only if I knock first.

97 characters, one line. `main.py` writes it to `/output/entry.txt` and
self-checks the gate (1–140 chars, single line, not only whitespace).

## Run it

```sh
python3 main.py
```
